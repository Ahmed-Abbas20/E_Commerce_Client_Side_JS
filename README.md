# 🛒 E-Commerce Client-Side JS  
An interactive and responsive front-end e-commerce web app built using **pure JavaScript**, HTML, and CSS — simple, elegant, and effective!

## 🚀 Features  
- 🧾 Product listing with clean UI  
- 🛍️ Add to cart and remove functionality  
- 🔢 Dynamic cart counter  
- 💰 Total price calculation in real-time  
- 💾 Data persistence via Local Storage  
- 📱 Mobile-friendly responsive layout  

## 🧠 Tech Stack  
- HTML5  
- CSS3  
- JavaScript (ES6+)  

## 📂 Project Structure

## 🛠 How to Use  
1. Clone this repo:  
   ```bash  
   git clone https://github.com/Ahmed-Abbas20/E_Commerce_Client_Side_JS.git  
   ```  
2. Open `index.html` in your browser.  
3. Enjoy the shopping experience!
